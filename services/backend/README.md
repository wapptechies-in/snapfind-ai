# SnapFind AI — Backend (`services/backend`)

FastAPI backend for SnapFind AI.

**Phase 1 status:** `IMPLEMENTED` — a single health-check route
(`GET /`) that the SnapFind Web dashboard uses to show whether the
backend is reachable. No authentication, no event/photo APIs yet —
those are `PLANNED` for Phase 2.

## Prerequisites

- Python 3.11+ (3.10 also works)
- pip

## Setup

```bash
cd services/backend
python3 -m venv .venv

# macOS/Linux
source .venv/bin/activate
# Windows (PowerShell)
.venv\Scripts\Activate.ps1

pip install -r requirements.txt
```

## Environment variables

From the **repo root**, copy `.env.example` to `.env` and adjust if
needed (the defaults work with the Docker Postgres setup in
`database/docker-compose.yml`):

```bash
cp ../../.env.example ../../.env
```

FastAPI reads `.env` from the current working directory, so when you run
`uvicorn` from inside `services/backend/`, keep a copy of `.env` there
too, or run uvicorn from the repo root with `--app-dir services/backend`.
Simplest for now: copy `.env` into `services/backend/.env` as well.

## Run

```bash
uvicorn app.main:app --reload --port 8000
```

You should see:

```
Uvicorn running on http://0.0.0.0:8000
```

## Verify it's working

Open http://localhost:8000 — you should see:

```json
{ "name": "SnapFind AI API", "status": "running", "environment": "development" }
```

Interactive docs (auto-generated by FastAPI): http://localhost:8000/docs

## Tests

```bash
pytest
```
